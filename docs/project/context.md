# Peta konteks proyek

Bukti dikumpulkan dari manifest yang dikenali, ekstensi source, dan path repository. Peta ini tidak menyimpulkan perilaku bisnis dan tidak menjalankan script proyek.

## Proyek

`vector-web`

## Package manager

`bun`
- Bukti: `package.json#packageManager`, `bun.lock`

## Stack pilihan

Bahasa: JavaScript, TypeScript
Framework: Next.js
Library dan integrasi: React (diperlukan oleh Next.js)

## Bukti stack terdeteksi

Bahasa: JavaScript, TypeScript
Framework: Next.js
Library dan integrasi: React (diperlukan oleh Next.js)

- Router Next.js: App Router

## Bukti repository

- Ekosistem: Manifest package JavaScript
- Ekstensi source ditemukan: `.mjs`, `.ts`, `.tsx`

## Fakta manifest

- **Dependency TypeScript:** `^5` — bukti: `package.json`
- **Dependency Next.js:** `16.4.6` — bukti: `package.json`
- **Dependency React:** `19.3.0` — bukti: `package.json`

## Command yang dideklarasikan

Pemanggilan ini berasal dari nama script di manifest. Definisi script tidak disalin atau dijalankan; periksa command terkait sebelum menjalankannya.
- `bun run build` — dideklarasikan di `package.json (build)`
- `bun run dev` — dideklarasikan di `package.json (dev)`
- `bun run lint` — dideklarasikan di `package.json (lint)`
- `bun run start` — dideklarasikan di `package.json (start)`

## Peta repository

Path contoh hanya petunjuk navigasi, bukan bukti perilaku.
